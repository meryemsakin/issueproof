# Launch readiness

Pushing a repository is not a launch. IssueProof earns a broad launch after a stranger can try it quickly and at least one external case demonstrates what its receipt adds.

## Required before broad promotion

- [x] Public npm package with a clean install path.
- [x] Linux, macOS, and Windows core CI.
- [x] Composite Action end-to-end coverage on all three runner families.
- [x] Process-tree timeout regression test.
- [x] Optional clean tracked-state worktree attempts.
- [x] Adversarial fingerprint equivalence/separation corpus.
- [x] Checklist-first issue evidence output.
- [ ] One reviewed receipt from a real external repository at an immutable commit.
- [ ] One published case study that states limitations and does not overclaim the verdict.
- [ ] Two maintainers or agent-tool users complete the quick start without live help.
- [ ] GitHub Marketplace listing is published from a release.
- [ ] Support path, response expectations, and known limitations are easy to find.

## Channel order

1. Existing upstream issue or PR, only when the receipt or fix adds material evidence.
2. GitHub Marketplace, so Action users have a native discovery and install surface.
3. A small technical audience in the maintainer/agent-tooling community, linking the case study and exact quick start.
4. Show HN only after the project is immediately runnable and the author is available to answer questions.

The Show HN submission should link the runnable repository rather than a marketing page. Hacker News asks authors not to post generated or AI-edited text, so the final title and opening comment must be written personally by the project author. Do not solicit votes or coordinated comments.

## Success signals for the first two weeks

- Clean-install attempts and confirmed receipts matter more than stars.
- Track setup failures, command classes, verdict distribution, operating systems, and false fingerprint merges/splits.
- Ask for one concrete sentence: what decision changed because the receipt existed?
- A PR merge is useful evidence only when the upstream change is independently valuable.
